# リリックモーション表現辞典（Lyric Motion Vocabulary）

Yura.js の歌詞演出は、パーティクルで文字を組み上げる `lyrics()` に加えて、
**Web ページ（HP）で文字を動かすときの定番表現**を DOM/CSS で再現する
`kineticLyrics()` を持っています。さらにその上に、Three.js の 3D 空間・配色の切り替え・
装飾・カメラワーク・つなぎ・質感までを一式で組み上げる **`lyricStage()`**
（HTML に貼るだけの `<yura-lyric-stage>`）があります。この文書は、その表現を一つずつ
**名前・呼び名・見え方**に言語化した辞典です。

「なんとなくかっこいい動き」を、指定できる語彙に置き換えることが目的です。
デザイナーが「ここは“せり上がり”で出して“沈む”で抜きたい」と言えば、
そのまま `enter: 'rise', exit: 'sink'` と書けます。

## 考え方：一行の一生を四つに分ける

歌詞の一行は、画面の上で次の順に生きます。

1. **配置（layout）** — どこに、どんな組み方で置くか（中央・下部テロップ・縦書き・見切れ大文字…）
2. **登場（enter）** — どう現れるか（マスクからせり上がる・焦点が合う・解読される…）
3. **保持（hold）** — 歌われている間、どう生きているか（漂う・拍で脈打つ・時々ずれる…）
4. **退場（exit）** — どう去るか（沈む・霧散する・バックスペースで消される…）

そして、この四つの組み合わせの「傾向」をまとめたものが **雰囲気（mood）** です。
雰囲気を選ぶと、各行の登場・保持・退場・配置がシードに従って自動で選ばれます
（同じシードなら毎回同じ結果。直前の行と同じ登場は選ばれません）。

## HP の文字表現を分解する

Web でよく見る文字演出は、ほとんどが次の部品の組み合わせです。
Yura.js ではすべての表現をこの部品（`GlyphPose`）で書いています。

| 部品 | CSS | 何に使うか |
|---|---|---|
| 移動 `x` `y`（em） | `translate()` | スライド、浮上、落下、飛散 |
| 自分の箱に対する移動 `tx` `ty`（%） | `translate(%)` | マスクからのせり上がり・沈み込み |
| 切り抜き `clip`（%） | `clip-path: inset()` | ワイプ、シャッター、観音開き、マスク |
| 拡大縮小 `scale` `sx` `sy` | `scale()` | ポップ、ズーム、ゴム伸び、潰れ |
| 回転 `rotate` `rx` `ry` `skew`（deg） | `rotate*()` `skewX()` | 起き上がり、横回転、ドミノ、スキュー |
| 透明度 `opacity` | `opacity` | フェード、タイプライター、ちらつき |
| ぼかし `blur`（em） | `filter: blur()` | 焦点送り、霧散 |
| 光 `glow`（em） | `text-shadow` | ネオン、きらめき |
| 色ずれ `split`（em） | `text-shadow` ×2 | グリッチ（色は CSS 変数 `--yura-split-a/b` で変更可） |
| 文字の差し替え `char` | テキスト | 解読（スクランブル）、記号化 |

さらに、**一文字ずつの時間差（スタッガー）**が表情を決めます。
どの文字から動くか（`order`: `ltr` 左から / `rtl` 右から / `center` 中央から /
`edges` 両端から / `random` ばらばら / `all` 一斉）と、時間差の強さ（`stagger` 0..1）
を各表現が持っています。

大きさはすべて em か %（文字自身の大きさ基準）で書かれているので、
画面サイズや解像度、端末が変わっても同じ見え方になります。
乱数はシード付きのハッシュだけを使うので、同じ時刻には必ず同じ絵になります
（書き出しやフレーム単位の確認ができます）。

## 使い方

```ts
import { kineticLyrics } from 'yura'

const run = kineticLyrics('#stage', [
  { text: '君の声が', at: 0 },
  { text: '夜を照らす', at: 3.2 },
  { text: 'もう一度', at: 6.4, accent: true },          // 決め（サビ頭など）
  { text: '縦に\n流れる', at: 9.6, layout: 'vertical' }, // 一部だけ手で指定
], { mood: 'emotional', seed: 7, bpm: 128 })

// 曲と同期させるなら clock に再生位置を渡す
// kineticLyrics('#stage', lines, { clock: () => audio.currentTime })
```

- `accent: true` の行は、強い登場（`stamp` / `zoom-in` / `glitch-in`）と拍に合わせた `pulse` で、中央に大きく出ます。
- OS の「視差効果を減らす」が有効な環境では、自動で `fade` / `still` の静かな表現に切り替わります（`reducedMotion` で上書き可）。
- 各行は `aria-label` に歌詞そのものを持ち、一文字ずつの要素は読み上げから外しているので、スクリーンリーダーでも歌詞として読めます。
- パーティクルのキャンバスの上に重ねても使えます（背景は透明、ポインター操作は下へ通します）。

## リリックステージ — Three.js × 文字

`lyricStage()` は、一つの歌詞から**ヒーローセクション丸ごと**を組み立てます。
下から順に次の層が重なり、すべてが一つの時計で同期します。

| 層 | 中身 |
|---|---|
| 世界 | Three.js の 3D 空間。カメラが行ごとに動き、拍で脈打ち、配色で塗り替わる。奥には今の行の巨大な残像が浮かぶ（THREE を渡さなければ CSS の背景） |
| 装飾（奥） | 透かし大文字・方眼・照準線など、文字の下に敷く図形 |
| 歌詞 | `kineticLyrics()` の文字（上の表現辞典すべて） |
| 装飾（手前） | 枠マーク・タイムコード・天地罫・ティッカーなど、画面を「設計されたもの」に見せる印 |
| つなぎ | 行の変わり目を覆う色面（ワイプ・斜め帯・アイリス…） |
| 質感 | 粒子ノイズ・走査線・紙・周辺減光 |
| フラッシュ | 決めの行の閃光（と画面の揺れ） |

**一行が一カット**です。行が変わるたびに、テーマの配色の中から**必ず別の配色へ切り替わり**、
カメラの動き（直前と同じものは選ばれない）、つなぎ、文字の登場が決まります。
決めの行（`accent: true` / `data-accent`）は必ずフラッシュでつながり、
カメラが一瞬寄って（クラッシュズーム）画面が揺れます。

### HTML に貼るだけ

```html
<script type="module">
  import * as THREE from 'three'
  import { defineLyricStage } from 'yura'
  defineLyricStage({ three: THREE })
</script>

<yura-lyric-stage theme="synthwave" bpm="128" song="曲名" artist="アーティスト">
  <p>夜明けの色を</p>
  <p>覚えてる</p>
  <p data-accent>ひかりが走る</p>
  <p data-layout="vertical">遠く とおく</p>
</yura-lyric-stage>
```

- 属性: `theme` `world` `mood` `camera` `transition` `seed` `bpm` `every` `loop` `song` `artist` `audio`（同期させる `<audio>` / `<video>` のセレクタ）。属性を変えるとその場で組み直します。
- 行ごとの指定: `data-at`（秒）`data-accent` `data-enter` `data-hold` `data-exit` `data-layout`。
- 書いた歌詞は画面からは隠れたまま**ページに残る**ので、検索エンジンにもスクリーンリーダーにも普通の文章として読まれます（ステージ自体は装飾扱い）。
- 大きさは置いた箱に合わせます（高さの指定がなければ 16:9）。文字の大きさは箱の短い辺から実行時に決まり、長い行は箱に収まるよう自動で縮みます。全画面のヒーローにも、縦長のカードにもそのまま入ります。
- 画面外にあるときは描画を止め、OS の「視差効果を減らす」設定ではカメラ・揺れ・閃光・つなぎを止めます。閃光は真っ白にならないよう上限を設けています。
- THREE を渡さない、または WebGL が使えない環境では、CSS の背景に切り替えて動き続けます（後者は `YURA-021` で一度だけ知らせます）。

### JavaScript から

```ts
import * as THREE from 'three'
import { lyricStage } from 'yura'

const stage = lyricStage('#hero', [
  { text: '夜明けの色を', at: 0 },
  { text: 'ひかりが走る', at: 6.2, accent: true },
], { three: THREE, theme: 'noir', bpm: 124, audio: document.querySelector('audio') })
```

## 組み合わせの定石

- **対になる登場と退場を選ぶ。** `rise` → `sink`、`drop` → `rise-out`、`scramble` → `scramble-out`、`typewriter` → `backspace` のように、同じ仕組みの往復にすると一本の映像として締まります。
- **退場の向きで次の行を呼ぶ。** `rise-out`（上へ抜ける）のあとに `rise`（下からせり上がる）を置くと、文字が縦に流れ続けるように見えます。
- **強い表現は決めの行だけに。** `stamp` `zoom-in` `scatter` は毎行使うと効かなくなります。`accent: true` の行に集めるのが基本です。
- **保持は歌の性格で選ぶ。** 長く伸ばす行には `float` `breathe`、リズムの立つ行には `pulse` `hop`、不穏な行には `jitter` `flicker` `glitch`。
- **テーマは「一曲の画づくり」を決める。** 配色・書体・質感・世界・よく使う動きがまとめて変わります。同じ歌詞でも `seed` を変えるだけで別の構成になるので、気に入るまで振り直せます。
- **配置で映像の主役を決める。** 歌詞が主役なら `center` `giant`、映像が主役なら `lower`。`vertical` は和の語り、`left` `right` は編集的な余白を生みます。

## 表現を増やすには

`packages/yura/src/motions.ts` の `ENTER` / `HOLD` / `EXIT` / `LAYOUT` に一項目足すだけです。
各項目は `ja`（呼び名）と `desc`（見え方の言語化）を必ず持ち、テストが次を機械的に確認します。

- 登場は `p = 1` で、退場は `p = 0` で、完全に静止状態と一致すること（保持へ継ぎ目なく渡るため）
- 登場は `p = 0` で、退場は `p = 1` で見えなくなっていること
- どんなシード・時刻・テンポでも CSS に `NaN` / `Infinity` が出ないこと
- この文書に名前が載っていること（載せ忘れるとテストが落ちます）
