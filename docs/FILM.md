# yuraFilm — 台本ひとつで、プロモ映像・解説映像・ショーリール

`yuraFilm()` は、**場面を並べた台本（JSON）**から映像を組み立てます。
問いかけのフック → 一語だけ色や斜体を効かせたステートメント → 製品の手順と UI カード →
数え上がる数字と点のグラフ → 振り返りのモザイク → ロゴ・ボタン・URL のエンドカード、という
**コードで作る短尺映像の定番の構成**を、場面の種類として持っています。

- 絵はすべて HTML/CSS、音楽と効果音はすべて Web Audio で**コードから合成**します。素材ファイルは要りません。
- どの瞬間の絵も台本と時刻だけで決まるので、プレビューと書き出しが同じ絵になります。
- 画面は固定の論理解像度（16:9 なら 1920×1080）で組んで箱に合わせて縮めるので、どの端末・どの PC でも同じ見え方です。
- `bun run film 台本.json` で、フレーム単位で正確な **MP4（音つき）** を書き出します。

プレビューは `bun run dev:film`（ルック・画角を切り替えて確認、「音つきで再生」で音も確認）。

## 書き出し

```bash
bun run film my-launch.json                 # → ./my-launch.mp4（音つき）
bun run film my-launch.json --out promo.mp4 --fps 60
bun run film my-launch.json --from 0 --to 6 # 一部だけ確認
bun run film my-launch.json --no-audio
```

Chrome（または Chromium）と ffmpeg を使います。見つからないときは `CHROME_PATH` / `FFMPEG_PATH` で場所を指定してください。
録画ではなく一コマずつ時刻を指定して撮るので、遅い PC でも同じ映像になります（時間がかかるだけです）。

## 台本

```json
{
  "title": "Yura.js",
  "look": "saas",
  "aspect": "16:9",
  "bpm": 112,
  "locale": "ja-JP",
  "brand": { "name": "Yura.js", "tagline": "コードだけで、映像をつくる。", "url": "example.com", "cta": "無料で始める" },
  "scenes": [
    { "kind": "title", "kicker": "For people who ship", "text": "次の動画、\n*何日*かかりますか？" },
    { "kind": "compare", "before": "編集ソフトで二週間", "after": "台本ひとつ" },
    { "kind": "steps", "steps": [{ "title": "場面を*書く*" }, { "title": "ルックを_選ぶ_" }, { "title": "MP4 を*書き出す*" }] },
    { "kind": "ui", "text": "ボタンを_一回_押すだけ。", "card": { "title": "New render", "wave": true, "checklist": ["場面", "音楽", "字幕"], "button": "Render" } },
    { "kind": "stat", "value": 238, "suffix": " 表現", "label": "モーションの語彙", "viz": "dots", "share": 0.35 },
    { "kind": "end" }
  ]
}
```

- **強調**: `*語*` アクセント色、`_語_` 細いセリフ体の斜体、`~~語~~` 打ち消し線、`==語==` マーカー、`\n` 改行。
- **全場面共通**: `duration`（秒。曲のテンポに合わせて拍の整数倍に揃います）、`transition`（入り方）、`caption`（字幕）、`label`（工程表示の名前）、`block`（`accent` / `dark` / `light` で場面全体を色面に）。
- **画角** `aspect`: `16:9`（YouTube・Web）、`9:16`（ショート・リール・TikTok）、`1:1`、`4:5`。縦長では自動で縦積みの組み方になります。
- **数字の書式** は `locale`（`ja-JP` `en-US` `pt-BR` …）に従います。

## 背景・文字処理・画面効果

どの場面にも、次の三つを足せます。一覧は [EFFECTS.md](EFFECTS.md) と [LYRIC_MOTION.md の文字処理](LYRIC_MOTION.md) にあります。

```json
{ "kind": "title", "text": "夜明けの*色*を", "bg": "sunburst", "treat": "extrude", "fx": ["zoom-punch", { "name": "light-sweep", "at": 1.2, "dur": 0.6 }], "camera": "crash-zoom" }
```

- `bg` — 背景（54 種: 青海波・麻の葉・市松・放射・同心円・街並み・夕日・雨の窓・VHS…）
- `treat` — 文字処理（63 種: 袋文字・立体・長い影・マーカー・網点・クローム・傍点・切り貼り…）
- `fx` — 画面効果（48 種: グリッチ・RGB分離・ズームパンチ・集中線・フィルム焼け・ブラウン管オフ…）。`at` は場面の頭からの秒、`dur` は長さ。

## 音

音楽は曲のテンポ（`bpm`）で、キック・ハイハット・ベース・パッドの4和音ループ（明るいルックは長調、暗いルックは短調）。
最初の1小節はパッドだけで始まり、パッドはキックのたびに少し沈みます（プロの音源のような「うねり」）。
効果音は絵に合わせて自動で置かれます: 場面転換のウーッシュ、数字が止まる瞬間と項目のポップ、カーソルのクリック、
ターミナルの打鍵、カウントダウンのチック、エンドカード前のライザーと着地のヒット。

## 作るときのコツ

- **一語だけ効かせる。** 見出しの全部を強調すると何も目立ちません。`*` か `_` は一行に一か所。
- **一場面一メッセージ。** 迷ったら場面を分けます。3秒で読めない量は多すぎます。
- **数字は具体的に。** `1,089` のような端数のある数字のほうが本物らしく見えます。`share` でグラフの割合も合わせます。
- **最後はエンドカード。** `brand.cta` と `brand.url` を入れると、押したくなるボタンと URL で締まります。
- **SNS 用は `9:16`。** 字幕（`caption`）を付けると、音を消して見る人にも伝わります。
