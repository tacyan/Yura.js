# yuraSite — 貼るだけで「作り込んだサイト」になる

制作会社が一件ずつ手で組むような Web の演出 ——
オープニング、文字が一文字ずつ立ち上がる見出し、幕が横切って現れる写真、
スクロールで速度が変わる帯、スクロールで再生される歌詞、ページ全体の配色の切り替え、
吸い付くボタン、追従するカーソル —— を、**HTML の属性だけ**で入れられるようにしたのが
`yuraSite()` です。

- JavaScript は **1行**。演出は `data-yura-*` 属性で指定します。
- 色と書体はテーマ一つで決まり、ページとリリックステージ（Three.js）が同じ配色で揃います。
- 大きさは実行時に測り、端末やサイズを決め打ちしません。
- 「視差効果を減らす」設定の人には、動きを付けずに最初から全部見せます。
- JavaScript が読み込めなかった場合も、中身は普通に表示されます（隠すのはスクリプトが準備できてから）。

完成例は `examples/site`（`bun run dev:site`）です。架空アーティストの新曲特設サイトを、
この文書に出てくる属性だけで作っています。

## 3ステップで導入

### 1. head に1行（ちらつき防止）

```html
<script>document.documentElement.classList.add('yura-js')</script>
```

スクリプトが読み込まれる前に、演出する要素が一瞬見えてしまうのを防ぎます。
スクリプトが失敗した場合は何も隠れないので、ページが真っ白になることはありません。

### 2. 起動する

npm（`yurayura`）/ バンドラの場合:

```js
import * as THREE from 'three'
import { yuraSite } from 'yurayura'

yuraSite({ theme: 'noir', three: THREE, opening: true })
```

ビルドなしで CDN から読む場合（`yurayura` 0.3.0 以降。バージョンは固定して使うのがおすすめです）:

```html
<script type="module">
  import * as THREE from 'https://cdn.jsdelivr.net/npm/three@0.168.0/build/three.module.js'
  import { yuraSite } from 'https://cdn.jsdelivr.net/npm/yurayura@0.3/dist/index.js'
  yuraSite({ theme: 'noir', three: THREE })
</script>
```

`yurayura` の配布ファイルは依存を含まない1つの ES モジュールなので、変換サービスを通さずにそのまま読み込めます。

`three` を渡すと `<yura-lyric-stage>` が 3D になります。渡さなくても、ステージは CSS の背景で動きます。

### 3. 属性を付ける

```html
<h1 data-yura-text="rise">言葉より先に、ひかりが走った。</h1>
<img src="cover.jpg" alt="" data-yura-reveal="curtain">
<div data-yura-marquee>NEW SINGLE ✦ OUT NOW ✦</div>
```

## 属性一覧

| 属性 | 何が起きるか | 値 |
|---|---|---|
| `data-yura-text` | 見出しや文章を一文字ずつに分けて、画面に入ったときに登場させる | 登場の名前（既定 `rise`）。[表現辞典](LYRIC_MOTION.md)の「登場」33種がすべて使えます |
| `data-yura-reveal` | 写真・カード・段落などのかたまりを、画面に入ったときに登場させる | 下の「かたまりの登場」から（既定 `fade-up`） |
| `data-yura-stagger` | 付けた要素の**子要素**を、一つずつ時間差で登場させる | 時間差の秒数（既定 0.08）。効果は同じ要素の `data-yura-reveal` で指定 |
| `data-yura-delay` | 登場を遅らせる | 秒 |
| `data-yura-duration` | 登場にかける時間 | 秒 |
| `data-yura-seed` | 文字の登場のばらつき（ランダム系の表現）を固定する | 整数 |
| `data-yura-marquee` | 中身を無限に流れる帯にする。スクロールすると加速して傾き、上に戻すと逆走する | 速さ（1秒に進む一周の割合、既定 0.06） |
| `data-yura-parallax` | スクロールに対して、奥行きがあるようにずれて動く | 強さ（例 0.2、負の値で逆向き） |
| `data-yura-counter` | 画面に入ったとき、0 から数え上げる | 目標の数（小数も可） |
| `data-yura-decimals` | 数え上げの小数点以下の桁数 | 整数 |
| `data-yura-prefix` / `data-yura-suffix` | 数字の前後に付ける文字 | 例 `¥` / `+` |
| `data-yura-magnetic` | ポインタに吸い寄せられるように傾く（ボタン向け） | 強さ 0〜1（既定 0.35） |
| `data-yura-cursor` | 追従カーソルがこの要素の上で大きくなり、この文字を表示する | 例 `View` `PLAY` |
| `data-yura-scheme` | このセクションが画面の中央にある間、ページ全体をテーマの N 番目の配色にする（なめらかに切り替わる） | 配色番号（0〜） |
| `data-yura-scrub` | 縦に長いセクションにして中の `<yura-lyric-stage>` を画面に固定し、**スクロール位置で歌詞を再生**する | セクションの長さ（既定 `400vh`） |

### かたまりの登場（`data-yura-reveal`）

| 名前 | 呼び名 | 見え方 |
|---|---|---|
| `fade-up` | ふわっと浮上 | 少し下から浮かびながら現れる。どんな要素にも合う、最も汎用的な出方。 |
| `mask` | マスク | 下から上へ、枠に切り抜かれながら姿を現す。写真やカードに使うと一気に上質になる。 |
| `wipe` | ワイプ | 左から右へ、拭き取られるように現れる。横長の写真や帯に。 |
| `curtain` | カーテン | アクセント色の幕が横切り、通り過ぎた跡に要素が現れる。制作会社のサイトでよく見る、最も「作り込んだ」印象の出方。 |
| `zoom` | ズームアウト | 大きく寄った状態から、ゆっくり引いて定位置に収まる。写真に奥行きと重みが出る。 |
| `iris` | アイリス | 中心から円が広がって現れる。丸い写真や、印象的な一枚に。 |
| `blinds` | ブラインド | 上下から開く。シャッターが開くような、機械的で締まった出方。 |

## すぐ使えるクラス

`yuraSite()` は、テーマの色と書体を CSS 変数（`--yura-bg` `--yura-fg` `--yura-sub`
`--yura-accent` `--yura-accent2` `--yura-dim` `--yura-display` `--yura-serif` `--yura-mono`）
として `<html>` に置き、次のクラスを用意します。ページの CSS は並べ方だけ書けば済みます。

| クラス | 用途 |
|---|---|
| `yura-display` | 画面幅に合わせて伸縮する、特大の見出し |
| `yura-title` | セクションの見出し |
| `yura-eyebrow` | 見出しの上に置く小さな英字ラベル（等幅・字間広め） |
| `yura-lead` | 導入文 |
| `yura-serif` | 明朝で組む |
| `yura-btn` | ホバーで色が下から満ちる、丸いボタン |
| `yura-link` | ホバーで下線が左から引かれるリンク |
| `yura-rule` | 細い区切り線 |

## オプション

```js
const site = yuraSite({
  theme: 'noir',        // 配色・書体（リリックステージと共通のテーマ）
  scheme: 0,            // 最初の配色番号
  three: THREE,         // <yura-lyric-stage> を 3D にする
  opening: { title: 'YOAKE', seconds: 1.6, once: true }, // オープニング（once: セッション中は1回だけ）
  cursor: true,         // 追従カーソル（マウスなど細かく指せる端末だけ）
  progress: true,       // 上端の読み進みバー
  base: true,           // 上の CSS 変数とクラスを入れる
})
site.setTheme('sakura') // ページ全体の配色を切り替える
site.refresh()          // 後から足した要素にも演出を付ける
site.destroy()          // 全部外す（中身はすべて見える状態に戻る）
```

### テーマ

| 名前 | 呼び名 | 性格 |
|---|---|---|
| `noir` | ノワール・シグナル | 漆黒と生成り。琥珀とシアンの色ズレが走る、夜の報道映像のような緊張感。黒い石柱が並ぶ空間をカメラがゆっくり進む。 |
| `crimson` | クリムゾン・データ | 深紅と白、そして黒。データが壊れていくような鋭さ。結晶の破片が回る中を、手持ちのカメラが揺れる。 |
| `hazard` | ハザード | 警告色の黄と黒、差し色の赤と青。計器のような目盛りと番号が並ぶ、工業的でポップな画面。床のグリッドを滑るように移動する。 |
| `bubblegum` | バブルガム | ショッキングピンクと白と群青。丸ゴシックが弾み、輪が回り続ける、甘くて明るいアイドルソングの画面。 |
| `ink` | 藍と紙 | 生成りの紙に藍の明朝、差し色に紅。雑誌の誌面のような余白と罫線。文字の宇宙を静かに漂う。 |
| `blueprint` | 青焼き | 青地に白い線。設計図のように寸法と方眼が画面を刻む。図面の中を真上から覗き込み、クレーンで持ち上がる。 |
| `sakura` | 夜桜 | 深い葡萄色の夜に、桜色と白。花びらが舞い落ちる中、縦書きの詞がほどけていく。 |
| `abyss` | 深海 | 群青から黒へ沈む青。発光するシアンの輪をくぐり、光の届かない場所へ潜っていく。 |
| `synthwave` | 夕焼けシンセ | 紫の空と夕陽、地平線まで続くネオンの格子。80年代の未来像を全速力で走る。 |
| `sumi` | 墨と朱 | 墨の黒と和紙の白、ひと筆の朱。明朝の大文字と落款のような朱の印。石柱の間を静かに抜けていく。 |
| `chroma` | モノ・RGB | 白と黒だけの画面に、赤・緑・青の版ズレ。印刷のミスのような色の分離が主役。 |
| `gilded` | 金夜 | 黒と金。光の輪がゆっくり回り、細い明朝がきらめく。授賞式のような格調。 |

## プロの仕上がりに見せるコツ

- **登場は「一種類を主役に」。** 見出しは `rise`、写真は `mask` か `curtain`、それ以外は `fade-up` —— のように役割ごとに決めて揃えると、一気に「設計された」印象になります。毎回違う演出にすると安っぽく見えます。
- **時間差（stagger）は 0.06〜0.12 秒。** カードや一覧は `data-yura-stagger` で一つずつ出すだけで、手作り感が消えます。
- **配色の切り替えは 2〜3 回まで。** `data-yura-scheme` でセクションごとに暗→明→暗と切り替えると、長いページにリズムが生まれます。
- **巨大な文字と小さなラベルの対比。** `yura-display` の見出しに `yura-eyebrow` の小さな番号（`01 — STORY`）を添えるのは、制作会社のサイトの定番の組み方です。
- **帯（marquee）は一枚に一、二本。** ページの区切りに置くと、スクロールの速さに反応して画面が生きて見えます。
- **スクロール再生の歌詞は「見せ場」に一つ。** `data-yura-scrub` のセクションは長く取る（`500vh` 前後）と、一行ずつ落ち着いて読めます。

## 配慮と性能

- 演出の動きはすべて一本の描画ループで処理し、画面外の要素の計算は省きます。レイアウトの読み取りを先にまとめて行い、そのあとで書き込むので、スクロール中にレイアウトが何度も計算し直されることがありません。
- 分割した見出しには元の文を `aria-label` で付けるので、スクリーンリーダーには一文として読まれます。見出しの中のリンクやボタンは分割せず、そのまま操作・読み上げできます。
- 数え上げの数字にも最終値を `aria-label` で付けます。
- 「視差効果を減らす」設定では、登場・数え上げ・帯・視差・カーソル・オープニングを止め、最初から完成した状態で表示します。
- 追従カーソルは本来のカーソルを消さずに重ねるだけなので、操作性は変わりません。
