# 背景と画面効果 — backdrops / screen effects

リリックステージ・映像（yuraFilm）・ホームページのどこでも使える、二つの層の辞典です。

- **背景（backdrop）**: 画面全体に敷く模様や風景。和の文様、図形のパターン、風景、画面の質感。CSS と SVG だけで描かれ、ゆっくり動くものは時刻だけで決まるので、プレビューと書き出しが同じ絵になります。
- **画面効果（screen effect）**: 画面全体にかける一瞬の効果。グリッチ、衝撃、光、印刷やモニターの質感、漫画の効果線、終わりの演出。

色はどちらも CSS 変数（テーマ・ルック・ページの配色）に従います。

## 使い方

```ts
// 映像: 場面ごとに背景と効果を指定
const scene = { kind: 'statement', text: '夜明けの*色*を', bg: 'seigaiha', fx: ['light-sweep', { name: 'zoom-punch', at: 1.2 }] }

// リリックステージ
lyricStage('#hero', lines, { theme: 'washi', backdrop: 'asanoha', fx: ['bloom', 'light-sweep'] })
```

```html
<!-- ホームページ: セクションの背景に -->
<section data-yura-bg="sunburst">…</section>
<!-- 貼るだけのステージ -->
<yura-lyric-stage theme="comic" backdrop="speed-lines" fx="focus-lines zoom-punch">…</yura-lyric-stage>
```

画面効果のうち、モザイク・ポスタリゼ・1bitディザ・輪郭抽出・波ゆがみ・ホイップブラーは SVG フィルターを使います。
`yuraFilm` と `lyricStage` は自動で読み込みます。自分のページで `fxFrame()` を直接使う場合は、`FX_SVG_DEFS` をページに一度だけ入れてください。
